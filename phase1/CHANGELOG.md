# 변경 기록

## v6 — 2026-11-04 · Backstory 인터페이스, Journey 접기, 정보량 축소 (SPEC.md v2.2)

- **Backstory 근거를 대본 드래그로**: 드래그 메뉴에 [Backstory] 추가(빈 곳·비트 안·일부 겹침 어디서나). 드래그한 대사가 근거로 저장되고, 대본 줄 번호 옆에 점이 생긴다. 카드에서는 근거를 "근거 1장 6행" 대신 대사 그대로 보여 주고 누르면 그 위치로 이동한다. Beats의 [+ Backstory]는 패널 안에서 바로 입력한다. Scripts를 덮던 Backstory 패널, 근거 장면 드롭다운, 줄 번호 입력, Journey의 Backstory 칸 제거.
- 일부만 겹치는 선택은 알림만 띄우고 끝나던 것을, 이유와 함께 [Backstory]를 고를 수 있게 함.
- **Journey 접기**: 장면별 비트 칩을 기본으로 접고, 개수 + 펼침 아이콘으로 연다. "표적" 라벨·"등장 X" 글자를 없애고 등장하지 않는 장면은 옅게.
- **펼침 아이콘·드롭다운 화살표 여백**: 모든 select 화살표를 오른쪽 12px 안쪽으로, 펼침 아이콘도 가장자리에서 띄움.
- **정보량 축소**: 접힌 비트 카드 = B 칩 + 한 줄(목적 또는 대사) + 펼침 아이콘. 장면·줄 위치, "✓ 완료", 행동동사 칩, 메모 개수, "캔버스" 태그 제거(완료는 칩 채움, 캔버스 여부는 카드를 옅게). 펼친 카드도 동사 한 줄 구성으로 단순화하고 빈 메모 영역은 숨김. 캔버스 비트 노드 = 칩 + 목적 + 대사 2줄(위치·행동동사·✓ 제거, ✕는 마우스를 올릴 때만). 해석 노드의 라벨과 연결 개수 제거. Agent 패널의 "참조할 해석" 라벨과 보기 필터, 카드의 작품명 표시 제거.

## v5 — 2026-11-04 · 범주 대신 비트 (SPEC.md v2.1)

연구진 논의 결론: 대본은 순간순간 감정과 상황이 바뀌어 범주로 묶기 어렵다. 장면 안의 세부 흐름을 담으려면 비트가 단위가 되어야 한다. 범주 뷰 자리에 비트를 넣는다.

- **Beats 패널**(화면 1 가운데, 화면 2 왼쪽)이 Character Notes의 범주를 대체. Backstory → 장면별 비트. 카드를 펼쳐 목적, 행동동사(동사N · 묶인 문장 · 동사), 메모를 편집. 목적 + 행동동사가 있으면 ✓ 완료. [범위 다시 선택] [비트 삭제].
- **Scripts**: 드래그 위치에 따라 메뉴가 달라짐. 빈 곳은 [비트로 만들기], 비트 안은 [행동동사] [메모], 일부 겹침은 거부. 모든 장면에서 비트를 만들 수 있음(v3는 표적 장면만).
- 대본 표시: 비트 배경·B 칩, 행동동사 진한 배경·밑줄·동사 라벨, 메모 점선.
- **선택 하이라이트를 연속 표시로 수정**: 글자마다 테두리가 그려져 칸마다 네모가 생기던 문제를 고침.
- v3에서 가져온 것: 비트 범위와 겹침 금지, B 번호·색, 목적, 문장 분할과 문장 단위 행동동사(다른 그룹에서 옮겨 오기), 범위 메모, 완료 판정, 범위 다시 선택과 범위 밖 표시, 관련 이벤트. 가져오지 않은 것: 비트 상세 화면, 1초 누르기, 완성보드.
- Journey: 장면별 비트 번호 칩(완료하면 채워짐). Connections: 비트 노드(목적·인용·행동동사). Agent: 연결 비트 2개 이상 + 해석 작성. 요청 스냅샷에 비트의 목적·행동동사·메모 포함.
- 위저드 콘솔: 실시간 미러·요청 상세·분기 후보 계산·타임라인 분류를 비트 기준으로.
- 데이터: `categories`, `moments` → `beats`. `nodes`·`links`는 `beatId` 기준.

## v4 — 2026-10-28 · 연구계획서·기획안 정렬 (SPEC.md v2)

v1~v3의 비트 분석 중심 구조를 걷어내고, 기획안(0811) 와이어프레임과 연구계획서 ver1.1의 절차·수집 항목에 맞춰 다시 만들었다.

- **화면 1 수집·정리**: Character Journey(Backstory + 장면, 범주 색 점, 등장 여부) · Character Notes(사용자 범주: 만들기·이름·색·순서·삭제·강조, 끌어서 범주 이동, 메모) · Scripts(모든 장면에서 드래그 → 모먼트 저장 → 범주 선택, 범주 색 하이라이트, 겹침 표시). Backstory 자유 기술 모먼트(근거 장면·줄 선택).
- **화면 2 연결·해석**: Connections 캔버스(모먼트 노드, 해석 노드의 해석명·해석 작성, 포트를 끌어 연결, 선 선택·삭제, 노드 이동, 빈 곳 끌어 이동) · Dramaturgy Agent(해석 단위 요청, 연결 2개 이상 + 해석 작성 조건, "'해석명' 참조됨", 채택 시 해석 노드에 "참고:" 칩).
- 고지 문구를 "응답은 연구진이 미리 준비한 자료 중에서 골라 보내 드립니다."로 변경.
- 삭제: 비트·목적·행동동사·비트 메뉴·비트 상세, 완성보드·해석본 .md, 줄 사이 메모, 시대배경·인물 관계·자유 질문 버튼.
- 위저드 콘솔: 실시간 미러를 화면·장면·Journey 요약·해석·범주별 모먼트로, 요청 상세를 해석 스냅샷으로, 응답 풀 필터를 분기·유사/대조·출처 유형으로. 타임라인 분류를 수집·정리 / 연결·해석 / 레퍼런스로.
- 데이터: `categories`, `moments`, `nodes`, `interps`, `links` 컬렉션 추가, 요청은 `interpId`+`snapshot`, 응답 카드에 `play`·`character`. 응답 풀은 `reference`·`fallback`만.
- 이벤트: 연구계획서 수집 항목(모먼트 생성·연결, 해석 작성, 레퍼런스 탐색·선택)에 맞춰 재정의(README 표).
- 수정: 화면 상태 저장을 debounce에서 throttle로 바꿔, 쉬지 않고 입력해도 1초 안에 저장되게 함.
- 데모 저장 키를 `actconnect-demo-v2`로 바꿔 이전 데모 데이터와 섞이지 않게 함. 샘플 응답 풀을 3개 분기 × 유사/대조 카드로 교체.

## v3 — 2026-10-08 · 씬 순서 보기 · 조합 · 조합 레퍼런스

Phase 1 최소 기능(① 극에 메모 → ② 메모를 구조화 → ③ 구조화한 정보로 레퍼런스)에 맞춰 ②와 ③을 보강.

- 완성보드에 **씬 순서로 보기** 추가: 대본 메모(생각·전사)와 비트의 목적·행동동사·비트 메모를 장면→줄→글자 순서로 한 목록에 표시. 각 항목에서 원래 위치로 이동.
- **조합**: 목록에서 항목을 골라 [조합 만들기] → 조합 카드에 항목과 "이 조합에서 읽은 것" 한 줄. 삭제 가능.
- **조합 레퍼런스 요청**: 조합 카드의 [이 조합으로 레퍼런스 찾기], 또는 AI 사이드바 목록에서 조합 선택. 요청에 조합 항목·해석·완성보드 세 칸이 함께 담김. 채택한 카드는 조합에 붙음.
- 위저드 콘솔: 요청 큐에 "레퍼런스 · 조합 N", 요청 내용에 조합 항목·해석·완성보드 표시, 분기 후보 계산에 조합 텍스트 반영, 실시간 화면에 조합 목록.

- 완성보드의 '대본 메모' 두 칸은 씬 순서 목록으로 대체. 해석본(.md)에 씬 순서·조합 절 추가.
